IAviso Seguro exposes a REST API built with FastAPI that powers AI-assisted workplace hazard triage. The API accepts free-text hazard notices, routes them to either a local Ollama model or Google Gemini, and returns structured proposals ready for human review. All endpoints are versioned under `/api/v1` except the top-level health check.

## Base URL

| Environment | Base URL |
|-------------|----------|
| Local development | `http://127.0.0.1:8000` |
| Docker (default) | `http://127.0.0.1:8000` |

Interactive API documentation (Swagger UI auto-generated by FastAPI) is available at:

```
http://127.0.0.1:8000/docs
```

## Authentication

No authentication is required to call any endpoint. The `EXTERNAL_API_KEY` environment variable is a **server-side secret** used by the backend to authenticate with the Gemini API — callers never send it and it is never reflected in responses.

## Request IDs

Every HTTP response includes an `X-Request-ID` header containing a server-generated UUID. This identifier is also embedded in error response bodies and can be used to correlate logs across a request lifecycle.

```
X-Request-ID: 3fa85f64-5717-4562-b3fc-2c963f66afa6
```

## Error Response Format

All error responses share a consistent envelope regardless of status code. The `code` field is a machine-readable string drawn from the known error code list below; `message` is a human-readable explanation in Spanish.

```json
{
  "error": {
    "code": "invalid_provider_output",
    "message": "El proveedor devolvió una respuesta inválida."
  },
  "request_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
}
```

### Error Codes

| Code | HTTP Status | Description |
|------|-------------|-------------|
| `notice_not_found` | 404 | The requested notice does not exist |
| `comparison_not_found` | 404 | The requested comparison does not exist |
| `review_conflict` | 409 | The proposal was already reviewed or its version changed |
| `comparison_review_conflict` | 409 | The comparison already has a human reference decision |
| `persistence_error` | 500 | A database write could not be completed |
| `invalid_risk_matrix` | 500 | The risk matrix file is missing or fails validation |
| `invalid_knowledge_base` | 500 | The prevention knowledge corpus is unavailable or invalid |
| `invalid_provider_output` | 502 | The AI provider returned a response that could not be parsed |
| `invalid_tool_arguments` | 502 | The provider called a tool with an invalid category or argument |
| `required_tool_not_executed` | 502 | The provider did not invoke the required tool during triage |
| `tool_step_limit_exceeded` | 502 | The provider exceeded the maximum number of permitted tool steps |
| `provider_rate_limited` | 429 | The provider has temporarily reached its rate limit |
| `provider_unavailable` | 503 | The provider is temporarily unreachable (e.g. Gemini key not set, Ollama not running) |

## Endpoint Reference

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/health` | API status and dependency health check |
| `GET` | `/api/v1/catalogs` | Fetch closed-domain value lists |
| `GET` | `/api/v1/risk-matrix` | Fetch the active risk matrix document |
| `POST` | `/api/v1/triage` | Submit a hazard notice for AI triage |
| `GET` | `/api/v1/notices` | List and filter triage proposals |
| `GET` | `/api/v1/notices/{notice_id}/audit-events` | Retrieve the audit trail for a notice |
| `POST` | `/api/v1/notices/{notice_id}/reviews` | Submit a human review decision |
| `POST` | `/api/v1/comparisons` | Run a notice through both providers concurrently |
| `POST` | `/api/v1/comparisons/{comparison_id}/review` | Save a human reference decision on a comparison |
| `GET` | `/api/v1/metrics/summary` | Historical aggregated performance summary |
| `POST` | `/api/v1/evaluations` | Run the synthetic benchmark |
