IAviso Seguro is an AI-assisted triage platform for workplace safety. Workers describe a dangerous situation in plain text; the system consults a risk matrix, proposes a category, urgency level, department, and summary, then presents the proposal to a safety technician for approval, modification, or rejection. Every AI output is a pending proposal — the final classification always requires human sign-off.

## What IAviso Seguro Does

<Steps>
  <Step title="Submit a hazard notice">
    A worker submits a free-text description of a dangerous situation via the React interface or the `POST /api/v1/triage` endpoint. The text is treated as data — it cannot influence tool selection or inject instructions.
  </Step>
  <Step title="AI proposes a classification">
    The system calls a configurable LLM (Ollama locally or Gemini externally). The model uses a bounded tool call to look up the matching risk matrix rule, retrieves relevant prevention documents, and returns a structured proposal: category, urgency, department, 10-word summary, and justification.
  </Step>
  <Step title="Technician reviews the proposal">
    Every proposal lands in `pending_review` status. A safety technician approves it as-is, modifies one or more fields, or rejects it entirely. Only a reviewed proposal becomes an accepted classification.
  </Step>
  <Step title="Audit trail is preserved">
    Every transition — creation, review, correction, and rejection — is recorded in an immutable audit log with timestamps, actor identity, and the before/after classification state.
  </Step>
</Steps>

## Key Capabilities

<CardGroup cols={2}>
  <Card title="Two AI Providers" icon="robot" href="/concepts/providers">
    Run triage with a local Ollama model or Google Gemini. Switch per request via the `provider` field — no silent fallbacks.
  </Card>
  <Card title="Risk Matrix" icon="table" href="/concepts/risk-matrix">
    Nine closed hazard categories mapped to urgency levels and departments in a versioned, validated JSON matrix.
  </Card>
  <Card title="RAG Evidence" icon="book-open" href="/concepts/rag-evidence">
    Each triage run retrieves relevant fragments from a versioned prevention corpus and attaches them as auditable evidence.
  </Card>
  <Card title="Provider Comparison" icon="scale-balanced" href="/guides/provider-comparison">
    Submit one notice to both providers concurrently and compare results, latency, tokens, and cost side by side.
  </Card>
  <Card title="Human Review Workflow" icon="user-check" href="/guides/human-review">
    Optimistic-concurrency versioning prevents duplicate reviews; a `409` is returned if two reviewers act simultaneously.
  </Card>
  <Card title="Evaluation Benchmark" icon="chart-bar" href="/guides/evaluation-benchmark">
    Run 14 labelled synthetic cases through both providers and measure category accuracy, JSON validity, latency, and cost.
  </Card>
</CardGroup>

<Note>
  IAviso Seguro is an academic prototype. All texts, matrices, and datasets included are synthetic and non-normative. No AI proposal replaces a professional safety assessment or an emergency protocol.
</Note>
